# Titanic Survival Prediction

## 1. Project Description
This project predicts whether a passenger survived the Titanic ship disaster using Machine Learning. The model learns from passenger information and predicts survival.

## 2. Dataset
The Titanic dataset contains passenger details such as age, gender, passenger class, and other information.

## 3. Technologies Used
- Python
- Pandas
- NumPy
- Scikit-learn
- Jupyter Notebook

## 4. Model Training
The dataset is prepared and processed before training the Machine Learning model. The trained model predicts whether a passenger survived or not.

## 5. Model Accuracy
The model achieved an accuracy of **81.01%** on the evaluation data.

## 6. Conclusion
This project demonstrates how Machine Learning can be used to predict passenger survival based on available information. The model achieved 81.01% accuracy on the evaluation data.
