# Movie Rating Prediction

## Project Overview
This project uses Machine Learning to estimate IMDb movie ratings based on movie details.

## Technologies Used
- Python
- Pandas
- Scikit-learn
- Matplotlib
- Jupyter Notebook

## Machine Learning Algorithm
Random Forest Regression

## Project Files
- `movie prediction.ipynb` — Notebook containing the project code, analysis, graphs, and dashboard.
- `movie_rating_model.pkl` — Saved trained model.
- `imdb_top_1000.csv` — Movie dataset.

## Project Workflow
1. Load and explore the dataset.
2. Clean and prepare the data.
3. Preprocess numerical and categorical features.
4. Train a Random Forest Regression model.
5. Evaluate predictions using RMSE and R².
6. Visualize actual and predicted ratings.
7. Create an interactive dashboard.

## Disclaimer
Predicted ratings are estimates from a machine learning model and are not official IMDb ratings.
