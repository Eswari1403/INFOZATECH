# Iris Flower Classification

This project predicts the species of an Iris flower using the K-Nearest Neighbors (KNN) machine learning algorithm.

## Features
- Loads the Iris dataset
- Visualizes flower measurements
- Trains a KNN classification model
- Evaluates model accuracy
- Predicts flower species using user inputs
- Provides an interactive Streamlit dashboard

## Technologies Used
- Python
- Pandas
- Scikit-learn
- Matplotlib
- Streamlit

## How to Run
Install the required libraries:

```bash
python -m pip install pandas numpy matplotlib scikit-learn streamlit
```

Run the dashboard:

```bash
python -m streamlit run Iris_Flower_Classification/dashboard.py
```
